# Portfolio brand

Approved identity assets and brand guidelines are in this directory. Detailed
specifications and rules are in [BRAND.md](BRAND.md).

| File | Use |
|------|-----|
| [mark-light.svg](mark-light.svg) | Mark for light backgrounds (transparent) |
| [mark-dark.svg](mark-dark.svg) | Mark for dark backgrounds (transparent) |
| [mark-paper.svg](mark-paper.svg) | Mark on 512×512 Paper background (matches `public/icon.svg`) |
| [lockup-light.svg](lockup-light.svg) | Horizontal lockup for light backgrounds |
| [lockup-dark.svg](lockup-dark.svg) | Horizontal lockup for dark backgrounds |
| [lockup-stacked-light.svg](lockup-stacked-light.svg) | Stacked lockup for light backgrounds |
| [lockup-stacked-dark.svg](lockup-stacked-dark.svg) | Stacked lockup for dark backgrounds |
| [favicon/](favicon/) | `favicon.svg`, PNG exports at 16/32/48/180/512, and `favicon.ico` |
| [palette.svg](palette.svg) | Approved palette sheet with WCAG 2.1 contrast |
| [brand-sheet.svg](brand-sheet.svg), [brand-sheet.png](brand-sheet.png) | Complete asset preview and small-size legibility test |
| [comparison.svg](comparison.svg), [comparison.png](comparison.png) | Light/dark surface comparison |

Light and dark variants share identical geometry. The Z glyph and wordmark swap
Ink (`#141210`) and Paper (`#FBF9F5`), while the accent bar remains Accent
(`#B03A1A`) throughout. Wordmarks are fully outlined vectors with zero font
dependencies. Standalone mark and lockup SVGs have transparent backgrounds and
tight viewBoxes; add padding in the containing layout when placing them.

Colours: Paper `#FBF9F5`, Ink `#141210`, Accent `#B03A1A`.
